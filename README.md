# ContaTools 🧮

ContaTools es una aplicación web moderna diseñada para simplificar y automatizar tareas contables cotidianas. Desarrollada con Next.js y enfocada en la eficiencia y facilidad de uso para profesionales contables.

![ContaTools Logo](https://conta-tools.vercel.app/_next/static/media/logo_transparent.8f509eef.svg)

## ✨ Características

### 📋 Generador de Cotizaciones

- Creación de cotizaciones profesionales en PDF
- Personalización de datos de empresa y cliente
- Gestión de productos y servicios
- Inclusión de cláusulas personalizadas
- Datos bancarios opcionales

### 🔍 Buscador de Claves SAT

- Búsqueda inteligente de claves de productos y servicios
- Búsqueda difusa para mejores resultados
- Acceso rápido desde cualquier parte de la aplicación
- Interfaz intuitiva y responsiva

### 💰 Calculadora de SDI (Salario Diario Integrado)

- Cálculo preciso del salario diario integrado
- Consideración de todas las variables necesarias
- Resultados instantáneos

### 💸 Control de Efectivo

- Registro y seguimiento de movimientos de efectivo
- Conteo y clasificación de denominaciones
- Generación de reportes

### 📊 Registro de Devoluciones

- Gestión de devoluciones y reembolsos
- Seguimiento de estados
- Cálculo automático de montos

### 📝 Registro de Gastos

- Captura y categorización de gastos
- Organización eficiente
- Historial detallado

## 🚀 Tecnologías Utilizadas

- **Frontend:** Next.js 13+
- **Estilos:** Tailwind CSS
- **UI Components:** Flowbite React
- **PDF Generation:** jsPDF
- **Búsqueda:** Fuse.js
- **Deployment:** Vercel

## 🎯 Objetivos del Proyecto

ContaTools nace con el propósito de simplificar las tareas contables diarias, ofreciendo herramientas intuitivas y eficientes que ahorran tiempo y reducen errores en procesos contables comunes.

## 📱 Responsive Design

La aplicación está completamente optimizada para dispositivos móviles y de escritorio, permitiendo realizar todas las operaciones desde cualquier dispositivo.
